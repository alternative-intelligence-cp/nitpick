; every atomic step and every `@npk_sys6(` call routed to the shim. A syscall
; written in a `module asm` block is neither -- the transformer rewrites IR, and
; assembly is not IR -- so it runs for real, with no point before it. Until

; STATES each one with the reason the explored build stays sound. Both runners
; hold the file to the census exactly: a syscall the census finds that no line
; states is `explore-asm-unlisted`, and a line the census does not find is
; `explore-asm-stale`.
;
