## 2. The design

### 2.1 E-6 — an unescaped by-value aggregate carries a term (S-97; step 0 if ratified)

**What.** In the encoder (`src/backend/smt/smt_encode.npk`), a binding of
aggregate type (a struct or an enum, a by-value local or parameter) whose name
is NOT escaped (`is_escaped(e, nm)` false: the address never taken by `@`,
`$$i`, `$$m` or an implicit `Self->` receiver — the set DEF-14 already
computes before the parameter loop) gets a versioned Int-sorted symbol of its
own, `s.k`, exactly as a scalar local does (`bind_find`/`version_next`). It is
an IDENTITY term: nothing is asserted about its value, and it is never
compared with a number. Then:

1. **A field read** `s.f` of a scalar field (an integer, a `bool`, a `char`, a
   pointer, a flag word) is the uninterpreted function
   `(|npk.f.<TYPEID>.<field>| s.k)` — one function symbol per (struct type
   id, field name), declared through `sym_new_fun` as `|npk.len|` is, of sort
   `(Int) <field sort>`; a nested read `s.a.b` composes (`(|f.b| (|f.a|
   s.k))`), and the inner aggregate needs no symbol of its own. A `List`
   field's `count` keeps the length symbol it has today (`place_len_term` on
   a bare name; through a field it is `(|npk.len| (|f.list| s.k))` — the same
   uninterpreted-function shape, and what lets `for (i in 0...s.items.count)`
   bound `s.items[i]`). A field of a twisted, float or `simd` kind takes the
   same function with its sort; a field whose value the fragment does not
   hold (a `dyn`, a channel) stays opaque per read as today. A limited field's
   rule (D-308) is asserted over the APPLIED term at each read, where today it
   is asserted over the fresh opaque one (`assert_field_rule`, unchanged in
   shape).
2. **A write to a field** `s.f = v` (an assignment through any path of `s`, a
   compound `s.f += v`, a `move`/`pass` out of an owning field, a write to a
   nested field `s.a.b = v`) bumps the version to `s.k+1` and states
   `(= (|f.f| s.k+1) <v's term>)` (or nothing, when `v` has no term) and, for
   every OTHER field `g` of the same struct type, `(= (|f.g| s.k+1) (|f.g|
   s.k))` — the update frame, bounded by the type's field count (a nested
   write frames the inner aggregate's siblings through the composed
   functions). A whole assignment `s = expr` bumps the version and states the
   per-field equalities when `expr` is a struct literal with terms, nothing
   otherwise.
3. **A loop head's havoc, a `pick` arm's merge, a `move` of `s`** bump the
   version through the same paths that bump a scalar's (`invalidate`,
   `invalidate_all`, the merge's `ite` chains — an aggregate version merges as
   an identity choice, `(ite c s.j s.k)`, which is what keeps a field read
   after an `if` equal on both arms when neither wrote it).
4. **A call argument.** Passing `s` PLAIN to a call changes nothing: the
   callee's parameter is its own binding — MEASURED at planning (§1's last
   bullet: both probes exit 19, the copyable and the owning case alike; the
   probes are committed beside the tools as `e6_probe_byval.npk` and
   `e6_probe_own.npk`). The executor re-runs them first (P-2); if either ever
   answers 99, a plain argument becomes a version bump at the call (sound),
   and the closing power drops to the loops whose body calls nothing with
   `s`. `@s` as an argument is already an escape (never named).
5. **A `pure never fails` call** in a contract or a measure over such an
   aggregate then applies the uninterpreted function to `s.k` (1.5.3's
   encoding, unchanged), so two reads of `raw item_member_count(ast, ld)`
   between which nothing writes `ld` are one term.

**Where** (the sites, each read before it is edited): `enc_expr`'s
`ExprMemberAccessExpr` arm (the field read — today `term_opaque` after
`assert_field_rule`); the assignment and compound-assignment walkers where a
field target invalidates today; `enc_param_bind`/`enc_param_entry` (a
parameter's first version; an aggregate parameter gets `s.1` where today it
gets nothing); the local-declaration walker (`P:s = P{…}` — the literal's
field facts); `invalidate`/`invalidate_all` (loops, calls that may write
memory — a by-value aggregate is NOT invalidated by a call unless (4) says
so); the merge after `if`/`when`/`pick`; the escape set's computation
(unchanged: it already lists every address-taken name).

**Soundness.** No alias to an unescaped by-value binding exists (D-004: a
pointer to a local needs `@`), and the callee's copy is the callee's — under
(4)'s measured answer. The pointee of a pointer (`x.count` with `Reach->:x`)
is NOT covered: any callee holding the pointer may write it (E-4, 1.6 leg B).

**The gate.** (i) The probe of (4) recorded first. (ii) `tests/verify/
terminate_field.npk`: a by-value struct's field as a loop's bound — its
`terminate` and `overflow` rows `discharged`, the check's compares assumes;
the same loop over the struct THROUGH A POINTER — `open`, the check kept; a
field written in the body between the reads — `open`; a `pure never fails`
call over the struct in the measure — `discharged`; each row named. (iii) The
manifest re-recorded (D-040): the 195 sites of §1 discharge, or the record
says which did not and why, read one by one; the gate over the shared rows
(`manifest_gate.py`, step 5's manifest against this one) moves NO verdict
and no (symbol, kind) discharged count falls. (iv) Every program's emission
byte-identical except where a guard was elided (the elided guards are the
rows that moved: count them, they are the difference). (v) The harness green,
the belts (an assume per elided guard), `parity` green.

### 2.2 E-5 — the bound-call fan-out (S-98; recommended: decided out)

DEF-86 made a trait-method callee reach every impl of its trait, because a
generic body is walked once and its impl is decided per instantiation. The
narrowing on offer: for a receiver whose type is a bound parameter `T` inside
generic function `G` (or a method of a generic impl), read `G`'s
instantiations (`FnInstTable`, `fninst_at`: `decl`, the argument window
`args_start/args_count` against the parameter window `params_start/
params_count`; a generic impl's through `InstanceTable` and the impl's target
pattern by `family_unify`), bind `T` per instance to its concrete argument,
and reach only `find_method(impls, bounds, types, ast, interns, concrete,
mname, 0).decl`; an argument that is itself a parameter of an ENCLOSING
generic follows that generic's instances in turn (a chain bounded by the
table); a chain reaching no concrete type, a `dyn` receiver and a `Self`
inside a trait's default body keep every impl. Sound; about 150 lines in
`reach_callee` (`src/frontend/analysis/reach.npk`), which would also need
`FnInstTable->` and `InstanceTable->` (`f.fninsts`, `f.inst` in
`pipeline.npk`) and the current function (`x.cur_fn` set in `reach_fn`).

**Why decide it out.** The over-approximation is in the SOUND direction (an
arm the program cannot enter costs a line; the direction it protects against
is a raise no arm names); its whole measured cost is four test files with one
arm each, unchanged since it was measured at 1.5.8b step 6b; and the
narrowing is a generic-chain walk inside a SAFETY analysis whose defect mode
— reaching too few impls — is exactly the hole DEF-86 closed. A precision
change with no safety gain inside the analysis that guards `failsafe`'s
exhaustiveness should wait for a program that pays for its absence in more
than an arm. Decided out means: the lead's row is closed with this
paragraph, the design above stays beside it, and the re-open trigger is a
measured cost — a library or app root that must name an identity its
instantiations can never raise in more than one arm. If the user prefers it
in, it is step 0b, after E-6, under the same gate shape (every rejection file
reports the same set; the four tests' `TbbErr` arms come off and REACH-002
does not ask for them back; the harness green).
