# 0.2.6 — Pick patterns and guards

**Cycle 0.2 — AST and parser.**

## Goal

`pick` in full: arms, patterns, destructuring, guards, and explicit fallthrough.

## Work

1. Arms separated by commas, patterns parenthesised, `(*)` as the catch-all.
2. Destructuring — `(Enum.Variant(binding))` and `(Struct { a, b })`.
3. Labelled arms and `fall label;` — there is **no implicit fallthrough**.
4. Guards, and `give` for a `pick` used as an expression (D-059).

## Two things that are gone

- **`(!)` is removed** (D-061). An arm believed unreachable is written with
  `#unreachable()`, which traps. `(!)` let the `ERR:` arm D-008 requires be
  elided, which is the least safe assumption available in the type.
- **`MacroPattern` is removed** (D-057). Macros expand to a fixed point before
  semantic analysis, so by the time a `pick` runs there is no macro invocation
  left to match.

## Done when

- Every pattern form parses; `(!)` is a diagnostic naming its replacement.
