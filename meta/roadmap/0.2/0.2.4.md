# 0.2.4 — Statements

**Cycle 0.2 — AST and parser.**

## Goal

Every statement form in `AST_REFERENCE.md` §2.

## Work

1. Blocks, `if`/`else`, `while`, `for`, `loop`, `till`, `when`/`then`/`end`.
2. `pass`, `fail`, `return`, `exit`, `!!!`, `defer`, `discard`.
3. `break` / `continue`, with labels; `fall label`.
4. **Assignment is a statement, not an expression** (D-060). `a = b = 5` does not
   parse, and `if (a = b)` is not expressible rather than being rejected by a
   rule.

## Watch for

`ForStmt.binding` is a full `ParamDecl` with a **required type**:
`for (int64:i in 1..3)`. The C three-clause form and untyped bindings are both
rejected (D-023).

## Done when

- Every statement form parses, with correct spans.
- `a = b = 5` fails to parse, and the diagnostic says why.
