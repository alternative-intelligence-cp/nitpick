# 0.2.5 — Declarations, contracts, attributes

**Cycle 0.2 — AST and parser.**

## Goal

Every top-level item, plus the contract and attribute syntax that decorates them.

## Work

1. `func`, `struct`, `enum`, `trait`, `impl`, `Type`, `Rules`, `macro`,
   `extern`, `opaque struct`, globals, `mod`, `use`.
2. Generic parameters after the name (D-030), never before.
3. `impl:Type` and `impl:Type:Trait` — **type always first, no connector**
   (D-031).
4. `opaque struct:Name;` — **`extern`-block item only** (D-066).
5. Contracts: `requires` / `ensures`, and `fails on … with errno` on `extern`
   functions — where the `with` keyword has its **one** meaning (D-082).
6. Attributes `#[name]` and `#[name(args)]`.

## Done when

- Every declaration in `AST_REFERENCE.md` §1 parses.
- An `extern` function without a failure contract is an error (D-002): "this C
  function is infallible" must be a claim someone wrote, not a default.
