# 0.1.4 — String, character, and template literals

**Cycle 0.1 — Lexer.**

## Goal

Strings in all three forms, characters, and the template literals that carry
interpolation.

## Work

1. Plain `"..."` with escapes.
2. **Raw `r"..."` and multi-line `"""..."""`** — both retained (D-024).
   Chapter 01 omitted them, and that omission described a prototype parser gap
   rather than a design decision.
3. Character literals, including escapes.
4. **Template literals** — `TEMPLATE_START` / `TEMPLATE_PART` / `TEMPLATE_END`
   around `&{ expr }` interpolation (§6.4).

## Why interpolation matters more than it looks

D-053 made formatting **ordinary functions returning `string`, spliced by
interpolation** — there is no format-specifier language and no `printf`. So
`&{ }` is not sugar here; it is the whole formatting mechanism, and the lexer is
where it starts.

## Done when

- All three string forms, characters, and templates lex.
- Rejection cases cover an unterminated string, a newline inside a plain string,
  and an unterminated interpolation.
