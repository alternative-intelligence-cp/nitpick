# 0.3.1 — The symbol table

**Cycle 0.3 — Modules, symbols, visibility.**

## Goal

One place that knows what every name in the program means.

## What a symbol is

A symbol binds a **name** to a **declaration**, in a **scope**, with a
**visibility**. The declaration is a `DeclId` — the AST already holds everything
else, and copying fields out of it would create a second place for a fact to
live, which is the defect this cycle set has spent its whole length removing.

Kinds, from `AST_REFERENCE.md` §1: function, struct, enum, trait, impl, rule,
macro, extern block, extern function, opaque type, global, module, associated
type, and the bindings introduced inside a body — parameters, locals, generic
parameters, `for` bindings, `pick` arm bindings.

## The two-phase collect (D-086)

**Every declaration in the graph is collected before any body is resolved.** Not
an optimisation — the property that makes a `use` cycle resolvable at all, and
the same one that already lets a function call another declared below it.

Phase 1 walks declarations only and never looks inside a `BlockStmt`. Phase 2
resolves bodies against the completed table.

## Work

1. `Symbol { name, decl, scope, visibility, kind }` and a growable table.
2. Scopes: a tree, each with a parent, holding name → symbol. A file is a scope,
   a `mod:name = { … }` is a nested one, a function body is one, a block is one.
3. Lookup walks outward to the module scope and stops. It does **not** walk into
   another module — that is what `use` is for, and 0.3.4 handles it.
4. **A duplicate declaration in one scope is an error naming both spans.** First
   wins is not a policy; it is a coin toss the reader cannot see.
5. Phase 1 over a module's declarations, with nested `mod` handled recursively.

## Watch for

**Interning makes name comparison an integer compare** (0.1), so a scope's map is
over `int32` and never over text. Intern index 0 is the reserved empty string
(0.2.4), so a symbol with no name is representable and distinct from a symbol
named by whatever was interned first.

## Done when

- Every declaration in a file becomes a symbol, nested `mod`s included.
- A duplicate names both spans.
- Lookup finds an outer-scope name and refuses to cross a module boundary.
