# 0.3.4 — Visibility and imports

**Cycle 0.3 — Modules, symbols, visibility.**

## Goal

`pub`, the four import kinds, and the rule that imports do not chain.

## Visibility (`MODULE_REFERENCE.md` §3)

**Binary: public or private.** Private is the default, private means "this module
and no other", and intra-module access to a private symbol is always permitted.

No `pub(crate)`, no `pub(super)`, no friend declarations. One rule.

## The four import kinds

| Form | Brings in |
|---|---|
| `use "m.npk".*;` | every `pub` symbol |
| `use "m.npk".square;` | one name |
| `use "m.npk".{square, pi};` | the named symbols |
| `use "m.npk" as math;` | the module, under one name |

All four already parse (0.2.5); this is what they mean.

## Imports do not chain

**`use` is strictly not transitive** (§2.3). A symbol imported into module A is
not visible to a module that imports A. Re-export is explicit: `pub use`.

That is the rule that keeps a module's surface **its own**, rather than the
transitive closure of everything its dependencies happened to import.

## Work

1. Mark each symbol `pub` or private from its declaration's flags (0.2.5 already
   parses them into `DECL_PUB`).
2. Apply each import kind to the importing scope, binding names to symbols in
   the imported module.
3. **Importing a private symbol by name is an error that says it is private**,
   not "not found". Those are different mistakes and the reader can act on
   exactly one of them.
4. `as` alias: bind the module itself, so `math.sqrt` resolves through it.
5. `pub use` re-exports; a plain `use` does not.
6. An import naming a symbol the module does not have is an error naming the
   module — and, where one is close, suggesting nothing. A guess that is wrong is
   worse than no guess.

## Watch for

**A wildcard import must not shadow a local declaration silently.** If `use
"m.npk".*` brings in `parse` and the importing file declares `parse`, the local
one wins and the collision is worth a diagnostic — a program whose meaning
changes when a dependency adds a symbol is the failure mode wildcard imports are
known for.

## Done when

- Private symbols are invisible across modules and visible within one.
- All four kinds bind what they should and nothing they should not.
- Importing a private name says *private*; importing a missing one says
  *missing*.
- `pub use` re-exports and `use` does not.
