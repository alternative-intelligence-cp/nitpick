# 0.1.3 — Numeric literals

**Cycle 0.1 — Lexer.**

## Goal

Every numeric literal form in `LEXICAL_REFERENCE.md` §6.

## Work

1. Decimal, hex (`0x`), binary (`0b`), octal, with `_` separators.
2. **Every width suffix** — `i8`…`i4096`, `u8`…`u4096`, and the twisted and
   fractional families.
3. Float literals with their suffixes.
4. The **balanced ternary and nonary** literals, which use the **suffix** form
   (`1T0t`, `2An`) — uniform with hex, binary and octal, per conflict 47.

## Watch for

- `0...4` is a **range**, not a malformed float. A float needs a digit after the
  dot. The seed hit this exact case in 0.0.2.
- An integer literal in expression position **requires** a suffix; an array size
  in type position is a bare count. That split was discovered writing the seed
  and is recorded in `SUBSET_1.md`.

## Done when

- Every literal form in §6 lexes to the right kind, value and width.
- Rejection cases cover a missing suffix, a bad digit for the radix, and an
  overlong literal.
