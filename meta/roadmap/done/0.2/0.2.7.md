# 0.2.7 — Parser diagnostics, recovery, and the suites

**Cycle 0.2 — AST and parser.**

## Goal

Every parse error has a stable code and an accurate span, recovery is tested
rather than assumed, and the cycle's suites are complete.

## Work

1. Codes for every parse error, centralised as in 0.1.6 — a mistyped code
   literal silently invents a new one.
2. Recovery under real conditions: several independent errors in one file must
   produce several diagnostics and **no phantoms**.
3. Complete the conformance suite — the whole grammar parses.
4. Complete the rejection suite, now aimed at the REAL parser. Every file there
   must still parse and be rejected later, which is D-085's rule finally
   enforced against the thing it was written about.

## Done when

- Every parse error has a code and a test.
- A file with several errors reports several, with no cascade.
- The suite passes, and closing the cycle pushes it.
