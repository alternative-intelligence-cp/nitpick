# 1.0.9c — The value and pattern lowerings

**Cycle 1.0, the tail's third part.** The rows of the disposition table that
are backend work with no decision behind them, plus D-169 at the checker and
the one builtin D-061 named and nobody wrote.

## What it builds

- **Multi-payload variants**: construction (`Ev.Move(1i32, 2i32)`) and the
  destructuring binding (`(Ev.Move(x, y))`) — the payload is a `{ … }` of the
  payloads, laid out as the enum's interned layout already says; the
  exhaustiveness analysis (0.5) already speaks for the arms.
- **Struct destructuring in `pick`** — the pattern tail 0.9.7 scheduled.
- **A call through a function-valued member** (`s.f(x)` where `f` is a field
  of function type, and `(s.f)(x)`): the checker distinguishes it from a UFCS
  method today; it lowers as an indirect call with one more step to fetch the
  callee.
- **`comptime(…)` in a runtime position** — the folder already produced the
  constant at 0.6; emit it.
- **The pipe** — "a call written the other way round" (`type_pipe`); lowers
  as the call.
- **Non-scalar casts enumerated**: every pair `cast_class` admits for a
  non-scalar (`=>`/`=>!`) is listed, then lowered or refused at the checker by
  name — none left to the rung.
- **The remaining builtins enumerated** against BUILTIN_REFERENCE: each is
  lowered or re-pointed by name at the cycle that consumes it.
- **D-169 at the checker**: `==`/`!=` on a struct, array, `Result`, two
  non-`NIL` `Optional`s, `string` or `dyn` refused with `TYPE_NOT_COMPARABLE`
  and the spelling that works; the 1.0.7 rung retires and
  `nonscalar_compare.npk` moves to the types suite.
- **`#unreachable()`** (D-061): a builtin that traps through D-142's route;
  the `(!)` message's advice becomes true.

## Tests

One executed program per lowered row; one rejection per checker refusal; the
rung suite shrinks by each retired string.

## Done when

Every row above has its outcome recorded; the fixpoint holds.
