# 1.0.2 — UFCS method calls

**Cycle 1.0.** `x.method()` lowering for concrete receivers — the syntax the
frontend has typed since 0.4.6 (UFCS was never removed) but no rung lowered. No new
decision; the type checker already resolves the call.

## What it builds

- **Method-call lowering** — `x.magnitude()` emits the call to the resolved free
  function or inherent method with `x` as the first argument, the receiver
  auto-addressed or copied per its parameter form (the same one-level dereference
  D-098 gives plain access).
- The concrete collections (`TokenList`, …) **become expressible** as method-bearing
  types — but are NOT yet rewritten in `src/` (C-13: the builder switches at 1.2).

## Tests

A struct with an inherent method called through `x.m()`; a free function called both
as `f(x)` and `x.f()` (UFCS equivalence, D-006); a method returning a value used in
an expression; auto-addressing of a by-pointer receiver.

## Done when

`x.method()` lowers and runs for inherent methods and UFCS free functions; the
equivalence with `f(x)` holds at runtime; the fixpoint holds.
