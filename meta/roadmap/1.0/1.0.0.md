# 1.0.0 — The mangling scheme (D-156)

**Cycle 1.0, the opening act.** Every instantiated type and function needs a
link-level name before anything downstream can emit one, so C-1 is settled and
implemented first. Decided: `D-156`.

## What it builds

- **Quoted symbols** `@"npk.<module>.<spelling>"` / `%"npk.<module>.<Type>"`, the
  spelling being D-108's source form (`Container<int32>`) embedded verbatim inside
  LLVM's quoted-identifier syntax. Hash-free (D-064 §6), path-free (D-078).
- **`ir_symbol` grows a module segment.** Today it is `@npk_<name>` / `@main`; the
  scheme adds the dotted, quoted form for module-scoped definitions, keeping
  `@main` and `@npk_failsafe` as the two named exceptions (the same two outside the
  `Result` regime, D-013).
- **`linkonce_odr` on instantiated definitions** — declarative until 1.2 links
  multiple objects; whole-program emission already dedups via D-108.

## What it retires

`check_duplicate_type_names` (emit_program.npk) — the interim refusal for two types
rendering one `%Name`. Module qualification dissolves the collision, so the guard
and its test go, replaced by a test that two same-named types in DIFFERENT modules
now emit distinct symbols and link.

## Tests

A program with a generic instantiated at two types emits two reversible symbols; a
type named `T` in module `a` and another in module `b` coexist (the retired refusal's
inversion); the emitted symbol for `Container<int32>` reads back to source by
inspection; no symbol embeds a build path (grep the IR for the repo root).

## Done when

The scheme emits for every definition; symbols are reversible and path-free; the
duplicate-name refusal is retired and its inversion passes; the fixpoint holds
(symbol bytes are emitted output — D-156 getting this hash/path-free is what keeps
1.2 stable).
