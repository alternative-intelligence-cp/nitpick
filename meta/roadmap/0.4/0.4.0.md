# 0.4.0 — The type representation

**Cycle 0.4 — Type system and checking.**

## Goal

One `Type` per type in the program, and one rule for when two are the same.

## Decision — type identity

**`TYPE_REFERENCE.md` gives layouts, not an identity rule.** Every comparison in
the checker depends on the answer, so it is settled here rather than discovered
in the middle of 0.4.2.

**Proposed: canonical interned types, compared by index.**

- One `int32` object for the whole program, so equality is an **integer compare**
  — and there is no structural walk to get subtly wrong.
- A type becomes usable as a **key**, which 0.4.7 needs to deduplicate
  monomorphized instantiations (D-064 caps depth at 64 and folds duplicates).
- It matches what the AST already does: index-based, never pointer-based, for the
  same reasons.

The cost is a lookup on construction. That is the right trade in a compiler whose
most repeated question is "are these the same type".

## Work

1. `Type` with a kind and its operands: scalar, pointer, slice, array, function,
   struct, enum, trait object, `Result<T>`, `cstring`, `any`, `Self`.
2. A type table that interns: constructing `int32->` twice yields one index.
3. Layouts from `TYPE_REFERENCE.md` — size and alignment per type. These are
   **not** throwaway: the seed's layouts already have to match, because its output
   and stage 1's interoperate until the fixpoint closes.
4. The scalar families, with their **semantic** distinctions recorded rather than
   inferred: `bool` and `char8` are one byte and are not integers; `tbb32` is
   `i32` and is an error-code type; `fd`/`pid`/`tid`/`uid`/`gid` compare and do
   not add (D-042).

## Watch for

**A type that is representationally identical to another is still a different
type**, and this is the layer that has to hold that line — nothing downstream
will. Storing "size 1, align 1" for `bool` and `char8` and calling them equal
would be correct about the machine and wrong about the language.

## Done when

- Constructing the same type twice yields the same index.
- Every type in `TYPE_REFERENCE.md` §§1–2, 9–11 has a layout, and a test asserts
  the sizes against `#size_of`.
- `bool`, `char8`, `uint8` and `tbb32` are four distinct types that all lower to
  one byte or four.
