# 0.9.7 — The control-flow and floor tail

**Cycle 0.9.** *(Added at merge review.)* The tree names its debts precisely:
`grep -rn '"0.9"' src/` returns **38 refusal sites**, and the subcycles before
this one own the type families but not the whole list. This subcycle owns the
rest, so the cycle can close with a grep, not a hope. The families already
placed: aggregates (0.9.2), wide ints (0.9.3), floats + float literals (0.9.4),
`tbb`/ERR semantics and the ERR pattern/sentinel (0.9.5), ranges, function
values, indirect calls, enum-tag casts, ternary `is`, char widths (0.9.6).

## Control flow

- **`for`** (with the `$` iteration variable — its own refusal site), **`loop`**,
  **`till`**, **`when`**, and **labelled `break`/`continue`**. All lower to the
  same block shapes `while` already proved; `for` over a range lands with 0.9.6's
  range normalization (its test already lives there). The counted-loop `step > 0`
  obligation is recorded for 1.3's catalogue as it lowers (per the README's
  carried-obligations rule).

## The `pick` tail

- **`pick` expressions** with **`give`** and **`fall`** — the value-producing
  form. F-2 of the borrow dive (a `give` that launders a borrow) becomes
  reachable here; land its fix with it or immediately after, per 0.9.8's ticket.
- **`pick` over a string** — the equality-chain lowering.
- **Guarded arms** — the guard is a `bool` refinement on an arm, evaluated after
  the pattern matches, lazily (the same no-both-arms rule 0.9.6 sets for `is`).
- **Range patterns, struct destructuring, multi-payload bindings** — the
  pattern-shape tail; the exhaustiveness analysis (0.5) already speaks for them,
  so this is lowering only, no new checking.

## The operator tail

- **`?` and `?!` on `Result`** — the fallback/or-trap pair (the `?`-on-tbb
  question is decided at 0.9.5: refused; D-099's one-wrapper rule holds).
- **`..^` expansion** and the **postfix operators** — with 0.9.6's forms they
  complete the expression grammar's lowering.

## The floor tail

- **`sys`** — the variadic syscall builtin (BUILTIN_REFERENCE §3), lowered onto
  the six-register trampoline the floor already carries (`npk_sys6`): N given
  arguments, zero-filled to six. **0.10.0 consumes this** (`mmap`/`munmap` for
  the heap go through `sys`, not a libc symbol) — it must land before the
  allocator cycle opens.
- **`#ptr_add<T>(p, n)`** — the pointer-stepping hash builtin the checker's own
  diagnostics promise ("pointer arithmetic goes through `#ptr_add`"), under the
  same wild-context confinement as `#wild_ptr`/`#wild_slice` (D-019/D-070's
  family: an unverifiable address operation is spelled, greppable, and confined).
- **`write_all` graduates** — D-141 promised it: the retry loop leaves the floor
  for `lib/nio.npk` the moment pointer stepping is expressible, and the floor
  loses a symbol. Do it here so the promise doesn't age.
- **The variadic-function refusal** is re-pointed, not lowered: `sys` is a
  builtin with its own call path, so nothing at this rung needs general
  user-defined variadics. Name their true owner (the FFI/extern rung that
  consumes them) in the refusal string, or descope by decision if no owner
  exists — but do not leave "0.9" in a string 0.9 does not honor.

## The mandatory-failsafe diagnostic (found by 0.9.0)

D-013 makes `failsafe` mandatory in every executable, and since D-142 the
LINKER enforces it mechanically (`npk_trap` references `@npk_failsafe`, so a
program without one fails to link — seven fixture tests were caught exactly
this way). What is missing is the FRONTEND saying so: a program whose root
module defines `main` and no `failsafe` should be refused by the checker with
its own code and a span on `main`, not by `ld.lld` with a symbol name. Land the
check here, with a module-rejection case; the linker remains the backstop.

## The exit criterion this subcycle establishes

**At cycle close, `grep -rn '"0.9"' src/` returns nothing.** Every site either
lowered here or had its refusal re-pointed to the cycle that truly owns it —
so no diagnostic ever names a finished cycle as the future. This is the same
staleness class `check_decisions_current` (0.9.1) hunts in the decision log,
applied to the rung strings; add the grep to the cycle's close checklist (and
to the harness if it earns a standing check).

## Tests

Programs per family (0.7.7 instrument): a `for`/`loop`/`till`/`when` quartet
with labelled `break`; a `pick` expression with `give`/`fall` and a guarded arm;
a `pick` over a string; a multi-payload destructure; `?` with a default and `?!`
trapping; a `sys` call (e.g. `getpid`) returning through `Result`; a `#ptr_add`
walk over an alloc'd buffer; `lib/nio.npk` flushing through its own loop after
`write_all` leaves the floor (the existing line-discipline test keeps passing —
that is the graduation's proof).

## Done when

Every family above lowers and runs (or its refusal names its true owner); `sys`
is available for 0.10.0; `write_all` is library code and the floor is one symbol
smaller; the exit-criterion grep is clean and recorded in the cycle close.
