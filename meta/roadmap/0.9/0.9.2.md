# 0.9.2 — Result, structs, enums, slices, arrays

**Cycle 0.9.** The aggregate lowering above subset 1. Subset 1 lowered a
single-word enum payload and a two-field `Result`; this subcycle lowers the general
shapes the type checker has accepted since 0.4.

## What lowers

- **`Result<T>` for every `T`**, at the D-069 two-field layout `{T, i32}` (the
  stored `is_error` was removed; `r.is_error` is the derived `error != 0`). Confirm
  the emitter matches `ll_wrap_result` and the runtime floor's `{T, i32}` shape — the
  three must agree or `llc` rejects the caller (the mismatch that was caught the
  first time, npkrt.ll §strings note).
- **Structs** with the general field set and correct padding/alignment
  (`TYPE_REFERENCE §9.1`). The `tt_haspt` pointer-presence bit the escape analysis
  reads (escape.npk `type_holds_pointer`) is written here as layout runs — keep it
  correct, since a wrong bit weakens the borrow check.
- **Enums** with richer payloads than one machine word — the general
  `{i32 tag, [pad], [max payload]}` shape (`TYPE_REFERENCE §9.3`). **Audit note
  (type-sys #11):** the §9.3 example `{i32, [4 x i8], [16 x i8]}` is misaligned (it
  yields struct align 4, so an 8-byte payload faults at odd addresses); lower with
  **max-field alignment**, and correct the doc example in the 0.9.8 doc-sync pass.
- **Slices `T[]`** at `{ptr, i64 len}` with bounds-checked indexing that traps to
  `failsafe` on out-of-range (D-070) — the runtime check that is where OOB detection
  comes from, since pointers are thin.
- **Fixed arrays `T[N]`** as value types with static-bounds-checked indexing
  (`TYPE_REFERENCE §9.2`), and **`[]` the zero array** (D-139).

## Tests

Executed-exit-code programs (0.7.7 instrument): a struct round-trip with a padded
field read back; an enum with a multi-word payload matched in a `pick`; a slice
indexed in-bounds (returns the element) and out-of-bounds (traps with the OOB
failsafe code); a fixed array copied by value into a function and mutated without
affecting the caller. Each asserts the exact exit code.

## Done when

Every aggregate shape the checker accepts either lowers and runs correctly or is
rung-refused; `check_kinds_lowered_or_refused` (0.9.1) shows no aggregate kind in the
third outcome; the enum-payload alignment is max-field and the doc example is
queued for correction.
