# 0.0.2 — Stage-0 build driver

**Cycle 0.0 — Foundations.**

## Goal

One command that compiles this repository's sources with stage 0, deterministically,
so that every later subcycle has a build to run.

## Why it is not `npkg`

`npkg` exists (`../npkg`) and is not usable here: it links `libntoml.a`, resolves
dependencies from a network registry, and carries a second manifest schema D-077
rejected. Building the real `npkg` requires a working compiler, which is what we
are building.

So this subcycle produces a **deliberately minimal driver** — enough to invoke
stage 0 over an ordered source set and report failure. The real thing arrives
once there is a compiler to write it with.

The driver is scaffolding in the same sense stage 0 is: **it is not in the
artifact**, and D-079's fixpoint check is what eventually proves that.

## Work

**1. Source ordering.** Deterministic and explicit — not a directory glob, whose
order varies by filesystem. D-078 requires byte-reproducible output, and a build
whose input order depends on the filesystem cannot deliver it.

**2. Invocation.** Stage 0 is `../nitpick/build/npkc`. Pin the path and **record
the exact stage-0 revision** used, because "which compiler built stage 1" is a
question the fixpoint check in 1.2 will need answered.

**3. Reproducibility from the start.** No timestamps, no absolute paths, no
hostnames in anything the driver emits. Cheap now; expensive to retrofit once
there are outputs to compare, and D-079's whole check depends on it.

**4. Failure is a failure.** A nonzero exit from stage 0 stops the build and
reports it. This mirrors D-067's reasoning — an invoked tool's failure is a value
the driver handles, never something to continue past.

## Done when

- One command builds the (currently empty) source set and exits zero.
- Running it twice produces identical output.
- The stage-0 revision is recorded in a committed file.

## Not in this subcycle

Linking, `llc` / `opt` invocation, incremental builds, `npkg test`. There is
nothing to link yet — the frontend emits nothing until cycle 0.7.
