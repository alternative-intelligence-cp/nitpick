# 1.3.2 — `tfp32/64/128/256`: the twisted fixed-point family (D-036/D-037/D-195)

The drift-critical core of the tier: deterministic fractional arithmetic
with the D-144 sticky-ERR discipline, on native `i32/i64/i128/i256`.

## Corrections settled at open (recorded on D-195)

- **Comparison on ERR TRAPS** (D-008 §5 — the rule is settled and its
  rationale explicit: NaN-style "all false" breaks trichotomy and hurts
  Z3). D-195's parenthetical said "false/true", copied from TYPE_REFERENCE
  §5's carry-over row; both corrected. One taint discipline, one trap code
  (−4100), both twisted families.
- **Bitwise and shifts on the raw representation are REFUSED**, striking
  §5's "on raw bits — useful for scaling" rows: `ERR << 1` is 0 — a
  one-instruction ERR laundry, the exact hole D-008's stickiness exists to
  close. tbb never admitted them; tfp doesn't either. Scaling is
  multiplication by a power-of-two constant, which is ERR-correct.
- **`tbb ↔ tfp` casts are CAST_IMPOSSIBLE**: the raw bits mean different
  values (scale 2^F), so a reinterpretation is a value forgery, not a
  conversion.

## The work

1. **Kind**: `TY_TFP` (a = bits; F = bits/2) through the walker sweep;
   `ll_type` → native `iN`; sizes 4/8/16/32, aligns 4/8/16/16. The
   sentinel and range tables are `tbb_min_decimal`/`tbb_max_decimal` —
   same carrier, same most-negative sentinel, shared on purpose.
2. **Literals, folded EXACTLY in subset-1 arithmetic** (the seed still
   builds src/, and wide ints are outside its subset): integer digits
   accumulate into u32 limbs (×10+digit); fraction digits produce F bits
   by the multiply-decimal-by-2 carry method; round half-even with a
   sticky bit; range past the width refuses TYPE-031. One helper serves
   checker (range) and emitter (the `iN` decimal constant); both literal
   forms work (`5tfp64`, `3.14tfp64`).
3. **Checker**: same-width-only arithmetic (the tbb arms generalize to
   both twisted kinds); FULL ordering (tfp is a number — unlike tbb's
   equality-only rule); `is_err` and the `ERR` sentinel admit tfp; unary
   `-` admitted (total under balance, D-008 §2); `.floor()`/`.trunc()`
   methods; the cast matrix (widening `=>`, narrowing/int/flt `=>!`,
   int→tfp `=>` iff B < I).
4. **Emitter**: add/sub/compare/is_err/ERR reuse the tbb machinery
   (generalized to twisted-bits); mul widens ×2, `ashr F` (floor, per
   §5), range-checks back; div: zero divisor → ERR, else widen, `shl F`,
   `sdiv` (truncation), range-check — `i512` intermediates for tfp256,
   inline-expanded like every wide div; casts with sentinel maps, ERR
   trapping on any cast OUT of the family; floor/trunc as masked adds
   under an ERR select.
5. **`ToString` in the prelude** (D-195): exact decimal expansion —
   integer part and `frac × 5^F` digits over the wide unsigned tier, raw
   bits reached by the store/load scratch trick; "ERR" for the sentinel;
   trailing zeros trimmed, mandatory fraction digit.
6. **Tests**: `tfp_basic` (exactness, arithmetic, saturation, sticky,
   div-zero→ERR, floor/trunc, casts, negation), `tfp_cmp_err` +
   `tfp_cast_err` (the −4100 traps), `tfp_tostring` (python-`fractions`
   known answers), rejection rows (width mixing, int mixing, bitwise,
   tbb↔tfp, out-of-range literal).
