# 1.3.1 — `simd<T, N>`: the vector mechanism (D-135, D-194)

The tier's foundation: the one primitive the library tier is built on.
Everything here implements D-194's ratified surface — see `1.3.0.md` G-4.

## The work

1. **Kind**: `TY_SIMD` (a = element, b = lanes) + `tt_simd`; size =
   elem × N, align = next power of two ≥ size, capped 64.
2. **The B-7 walker sweep**, enumerated up front (the D-182 lesson — five
   silent breaks): `type_drops` (false), frontend `type_subst` (rebuild
   with substituted element), backend `subst_emitted_type`'s has_elem
   list, `field_holds_ptr` (false), escape's `type_holds_pointer` (false),
   `type_display` ("simd<T, N>"), `ll_type` ("<N x T>" — with a scalar
   belt: only substitution can mint a non-scalar element, so a non-scalar
   here is LL_BROKEN, honestly a defect).
3. **Resolution**: the `resolve_generic_builtin` branch — element in the
   admitted set (int/uint 8..64, flt32/64, bool), N comptime in 2..64,
   total ≤ 64 bytes.
4. **Checker**: type-directed `simd(…)` ctor (N args or 1 = splat);
   elementwise binops (int: `+ - * / % & | ^ << >>`; flt: `+ - * /`;
   bool: none); comparisons → `simd<bool, N>`; `v[i]` read/write typed at
   the element; `.len`; methods `.sum/.min/.max` (numeric) and
   `.all/.any` (bool); casts `simd<T,N> => simd<U,N>` under scalar rules.
5. **Backend**: ctor (insertelement chain; splat = one value into every
   lane), elementwise ops (the scalar opcodes take vector operands), the
   D-007 vector div guards (any-lane zero → DivByZero, any-lane
   INT_MIN/−1 → DivOverflow — one compare + `llvm.vector.reduce.or`),
   compares (icmp/fcmp → `<N x i1>` → zext `<N x i8>`), lane read
   (bounds-check + extractelement), lane write (load/insert/store),
   reductions (`llvm.vector.reduce.*`, float `.sum()` ORDERED), casts
   (the scalar cast opcodes on vector types). Intrinsic `declare` lines
   emitted on use.
6. **Tests**: `simd_basic.npk` (ctor, splat, int/flt arithmetic, compare
   + all/any, lanes r/w, .len, reductions, casts), the three guard
   programs (`simd_div0`, `simd_divmin`, `simd_oob`), and
   `types/rejection/simd_rules.npk` (bad element, bad N, arity, ctor
   without annotation, N-changing cast, lossy `=>`, bool arithmetic,
   mixed operands).
7. `// ll:` markers; the vector-constructor rung at `ir_expr:957` retires;
   the arithmetic rung stays for the still-unlowered families.
