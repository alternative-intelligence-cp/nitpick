# 1.1.1 — The `src/` sweep: every `raw` and `drop` licensed or rewritten

**Cycle 1.1.** The middle third of D-163: the compiler's own sources are
brought under the licence — ~868 clauses, ~1,000 rewritten sites — under the
instrument, the 0.8.0 shape at its scale. `raw` and `drop` still do not refuse;
the instrument's `src/` + `lib/` + `tools/` count reaching zero is the exit
criterion, and 1.1.2 flips the rule after `tests/` follows.

## The worklist (from 1.1.0's instrument; the heuristic's estimate in brackets)

| class | what happens | estimate |
|---|---|---|
| `raw` on a callee that never fails | the callee gains `never fails`; the body check verifies the claim | ~5,500 sites, ~728 functions |
| `drop` on a never-failing `NIL` callee — the intended use | the callee gains `never fails` | ~1,170 sites, ~144 functions (overlap with the above: ~868 total) |
| `drop` on a never-failing callee **with a value** | `discard(raw f());` | ~90 (`lexer_advance` ×42, `te_error` ×31, `lay_field` ×13) |
| `raw` on a callee that **may fail** | rewritten — see below | ~262 |
| `drop` on a callee that **may fail** | rewritten — see below | ~741 (450 `NIL`, 291 with a value) |
| `raw` / `drop` on a builtin | per the `fails` column | ~98 |
| bare statements | `drop` (now licensed) | 2 |

**Resolve transitive may-fail at the root, not the leaves.** `p_expect` ×144
and `p_advance` ×82 are "may fail" only because `p_peek` relays `tokenlist_at`,
which `fail`s on range — after `p_peek` has bounds-checked. One in-range
accessor, or one `?!` on the provably-impossible branch, makes the whole parser
family `never fails`, and 226 `drop p_*` sites become licensed without being
touched. The same shape recurs under the analysis walkers (`assign_expr`,
`exhaust_expr`, `locks_expr` …): find the accessor at the bottom, decide
*there*, and the count collapses. The instrument's per-callee grouping is what
makes this visible; do not work the list top to bottom.

**The rewrite rule for a genuinely may-fail site, in order of preference:**

1. **`relay`** when the enclosing function returns a `Result` and the failure
   should reach the caller — the honest answer for the driver's stage calls
   (`drop check_module(…)` → `relay check_module(…);`) and for accessor
   failures that are internal defects: a defect should surface as a
   diagnostic, not as node 0 or a skipped stage. For a value-returning callee:
   `discard(relay f());` if the value is unused.
2. **`?! <code>`** when the enclosing function cannot return a `Result`
   (`main`, a `never fails` function) or the failure is an invariant violation
   with no caller able to act. The code is a D-141-space internal-defect code,
   not `1`.
3. **An `is_err` branch** when the failure is meaningful and handled here.

Never `? NIL` / `? <zero>` as a mechanical replacement: that is the old
behaviour with the swallow written down, and the point of the sweep is to stop
continuing past failures. The sweep's closing note lists every `? NIL` it did
write and why.

**Each may-fail site is read, not patterned.** Every one is a place the
compiler today continues on a wrong object or past a failed stage; the sweep is
also the audit of whether any of them has been *reached* — a site whose failure
path is live is a bug found, and is logged in the closing note with its repair.

## Order of work

1. The roots: `types.npk`, `ast.npk`, `symbols.npk`, `module_graph.npk`,
   `parser.npk`, `tokens` — the accessors everything else `raw`s and `drop`s.
   Decide each accessor's contract once; the instrument's count should fall by
   thousands here.
2. `src/frontend/parse_*.npk`, the `*_codes.npk`, `resolve*.npk`, `type_*.npk`.
3. `src/frontend/analysis/`, `src/frontend/macro/`.
4. `src/driver/pipeline.npk` — the stage calls become `relay`; this is the one
   place the rewrite changes the compiler's observable behaviour (an internal
   defect in a stage now stops the pipeline with a diagnostic instead of
   reaching the emitter), and it gets its own conformance case.
5. `src/backend/`, `src/main.npk`, `tools/`, `lib/`.
6. The fixpoint, re-proven after each group — the clauses change no byte; the
   rewrites change bytes only where a branch now exists.

## Tests

`tests/conformance/`: a program through the pipeline with a planted internal
defect in a stage now exits through the error path it previously swallowed.
The `selfhost` stage stays green throughout — each group lands compiling.

## Done when

- `check_raw_licensed` reports **zero** for `src/`, `lib/`, `tools/`.
- Every may-fail site is closed with a classified count (root-resolved /
  `relay` / `?!` / handled / `? NIL`-with-reason) and a note of every one whose
  failure path turned out to be live.
- The fixpoint holds; the harness is green on a full run.
