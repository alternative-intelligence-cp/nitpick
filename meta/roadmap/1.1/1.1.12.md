# 1.1.12 — The reactor, and the streams over it

**Decision:** D-184 (B-3a closed at stage a). **Gated on:** D-176 (deadlines),
D-177 (coroutines), D-181 (threads).

The executor's waiting story before this subcycle ended at the futex: a task
could wait on time, on a channel, on a lock — never on a DESCRIPTOR. This
subcycle adds the one I/O suspension the rest of the I/O surface is loops
around, then the streams themselves.

## a — the reactor core — DONE (D-184)

**epoll, and only epoll — no timerfd.** The executor already owns a deadline
machine (the sleeper list, the futex wait's absolute timeout); a timerfd
would restate it as a descriptor. Once armed, the idle wait is `epoll_pwait`
whose ms timeout (rounded UP) carries the same deadline the futex wait took.

- `suspend_io(fd, events, abs)` — the inline suspension: register one-shot,
  park exactly as `suspend_until` (same wind-up tail). Prelude
  `io_ready(fd, events, within)` is the `Result` face: `DeadlineExceeded`
  past the deadline; success means readiness was SIGNALLED — re-try the
  syscall, and a retry that still blocks calls it again.
- `io_unwatch(fd)` is **deferred inside `io_ready`**: the registration lives
  exactly as long as the wait. A one-shot left armed past its frame is a
  fire into freed memory — found by review before it found us.
- First `io_ready` creates epoll + eventfd (release-published); the eventfd
  rides the set with payload 0 as the drain marker, and both rousers
  (channel wake, wind-up) write it after their futex protocol. The epoll
  branch re-checks the park word before sleeping — the futex's kernel-side
  expected-0 compare, done by hand; skipping it is a sleep-through-a-wake.
- A ctl failure past creation (EPERM: a regular file; EBADF) dues the task
  NOW — the caller's re-tried syscall reports the errno as an ordinary
  `Result`. Only creating the reactor traps. Files behind `io_ready` read.
- **The task-identity rule** (the find of the rung, not reactor-specific):
  awaits drive children inline, so the frame a nested wait is lowered in is
  NOT the frame the sweep sleeps and wakes — the task root is. The executor
  records `cur_task` (slot 13) at its one resume site, and EVERY waiter
  registration resolves it: channel/lock/condvar/barrier link + unlink, and
  the reactor's payload. Latent until now because every channel test waited
  at task-root level; `nested_wait.npk` (helper-coroutine recv, cross-thread
  sender, stress 40) regresses it.
- `sys` accepts pointer arguments: `ptrtoint` at the trampoline — the one
  place an address becomes a number (`=>!` still refuses ptr→int). The old
  arm `sext`ed every non-i64, which llc rejects; latent, nothing had passed
  a pointer.
- io_uring: **not going in before Astrée** — a decision, not a deferral (an
  SQE owns its buffer past the call's return; a categorically larger
  ownership story, and a second reactor to verify).

Tests: `io_ready_basic.npk` (nonblocking pipe; deadline on silence, then a
writer thread and the byte, stress 40), `nested_wait.npk` (stress 40).

## b — owned descriptors and byte streams — DONE (D-185)

- **`OwnedFd`** (TY 39): the value is the kernel's i32, the generated drop
  closes it — §6's "no close in the surface". `own_fd(f)` wraps;
  `release_fd(move o)` unwraps for a caller that must observe close's
  verdict (the move defuses the drop). `.value` reads without consuming;
  writing it refuses. Proven by descriptor exhaustion: 1500 opens through
  owning scopes, no EMFILE.
- **Scope-bound = the borrow wall**: `type_contains_borrow` answers true —
  channels refuse the element (streams included), borrows refuse at spawns.
  A MOVE into a spawn is legal (join-bounded, the owning-string precedent);
  raw-number-then-`own_fd` is the cross-thread construction form.
- **`Path` + `path_parse`** — absolute, no interior NUL, `..`-above-root
  refused, lexically normalized. No static methods exist, so construction
  is a FUNCTION (`channel()`'s idiom); IO_REFERENCE amended.
- **`Reader`/`Writer` traits** as specified, with `Self->` receivers and
  `within` (D-176). `ByteReader`/`ByteWriter` retry loops: `WouldBlock`
  (11) waits on `io_ready` for the time that remains, `Interrupted` (4)
  retries, everything else forwards verbatim. `Whence` seek; no buffering
  at this layer.
- **TYPE-048**: an impl must keep its trait method's `async` — a sync body
  driven through the coroutine frame protocol is memory corruption.
- **Fixed on the way**: the awaited-method child frame seeded `Self->`
  receivers BY VALUE (first pointer-receiver await dereferenced its own fd
  number); `string_slice` views let `x = string_slice(x,…)` free the body
  under the view — quarantine-caught in `path_parse`; the language-level
  hole is OPEN_DECISIONS S-1, pre-Astrée.

Tests: `streams_file.npk` (normalize, trait write/read, seek, EOF, 1500
drop-closes, path refusals), `streams_pipe.npk` (EAGAIN→`io_ready` under a
writer thread; the writer's DROP closes its end and the reader sees IoEof;
stress 40), `stream_channel_elem.npk` (RUNG-001), `stream_rules.npk`
(TYPE-046/007), TYPE-048 in `async_rules.npk`.

## c — the text layer, std streams, buffering — DONE (D-185 addendum)

- **Composition is types, never modes**: `TextWriter<W: Writer>` translates
  (`LineEnding` a creation parameter; readers translate unconditionally,
  split-`\r\n` included — `text_pipe.npk` forces it across a live pipe);
  `LineBufWriter<W: Writer>` buffers by line. A mode field would be D-072's
  rejected shape; D-076 is honored by construction.
- **Std streams**: `std_in`/`std_out`/`std_err` constructors — each owns a
  `F_DUPFD_CLOEXEC` dup (scope-exit close can never touch 0/1/2), policies
  baked into the return types, descriptors kept BLOCKING (`O_NONBLOCK`
  would leak through the shared OFD to the parent) — the one stated D-071
  exception.
- **`string_bytes`**: the string→slice bridge (borrowed view, no copy).
- **Text API as free generic functions** (D-161: no inherent impls over
  families), parameters inferred from `@receiver`.
- **Three compiler fixes forced out**: the raw-template-field-resolve class
  (drop-body generator + `gives_shape_ok` + escape's `dest_can_hold` — all
  now through `struct_field`'s bound walk); the `Ident { Ident :`
  struct-literal/block lookahead (the fourth token — `=` or `;` — settles a
  declaration); awaited bound-calls in generic bodies (substitution
  outranks the recorded template symbol; pointer receiver peeled).

Tests: `text_roundtrip.npk` (CrLf bytes on disk; lines back including the
unterminated tail; std ctors dup + drop), `text_pipe.npk` (split-`\r\n`
across a thread boundary, IoEof from the writer's drop; stress 40).

## d — async methods behind `dyn` — DONE (D-185 second addendum). 1.1.12 COMPLETE.

- Async slots hold the concrete RESUME; a SIZE TAIL (one entry per async
  method, declaration order) points at `@"npk.fsz.<frame>"` globals emitted
  beside each frame definition (vtables precede the frames they name, and
  gep constants demand defined types; globals forward-reference freely).
- The await site builds the frame from the TRAIT's shape through a per-site
  synthetic prefix type — header as `fnem_frame_init` writes it, slot 0 =
  the vtable's resume, receiver = the dyn's data pointer — and drives the
  standard inline loop, resume re-read from frame slot 0 each entry.
- Object safety: rule 4 NARROWED — async is object-safe with a `Self->`
  receiver; by-value `Self` alone still disqualifies. Rule 2 admits
  `Self->` as the receiver (pointer-to-Self IS the erased-safe form) —
  unblocking every `Self->`-receiver trait behind `dyn`.
- Latent sync fix: thunks loaded the concrete by value for EVERY receiver;
  a pointer receiver now takes `%d` itself.
- `dyn_stream.npk`: one report fn through `dyn Writer`, a plain ByteWriter
  vs a family-instance CrLf TextWriter — `\n` in one file, `\r\n` in the
  other. Adopting `dyn Writer` in npkc's own diagnostics = 1.3 material.
