# 1.1.9 — Threads (D-181, C-9's thread half)

**Cycle 1.1.** The `thread` modifier, the per-thread executor, and the
lexical join — built in three stages, each harness-gated.

- **A — the surface.** `thread` joins the function modifiers; the `joins
  <const Duration>` clause joins the contract position. The checker's rules:
  a `thread` function is `async` (D-071 — a thread's entry point is an async
  func), its success type is `NIL` (D-179's spawn rule, inherited), it is
  started only by the spawn form, and `main`/`failsafe` may not carry it.
  The backend refuses a thread spawn by name until stage C.
- **B — the executor becomes a struct.** Every word 1.1.8 made a runtime
  global — ready queue, sleepers, park request and word, join deadline,
  origin-chain ring — moves into `%npk.exec`, reached through one accessor.
  Still one executor, still one thread: nothing observable changes, and the
  full harness proves it. The freeze flag stays global by D-063.
- **C — real threads.** `clone(2)` with a guard-paged 2 MiB stack and
  `CLONE_SETTLS` installing the `%fs:8` executor pointer; the child's root
  task is the thread body; `CHILD_CLEARTID` is the join, waited on under the
  declaration's deadline. `hardware_concurrency` via `sched_getaffinity`.
  Tests: two threads making progress concurrently, a thread's error relayed
  into the spawner, a thread outliving its deadline contained.

## Done when

A program spawns a thread, both threads run tasks, scope exit joins under a
stated deadline, and every existing property (D-063's freeze, D-180's borrow
ban, D-179's named failures) holds across the boundary.

## Outcome (stages A/B/C)

**A** put `thread` beside `async` and `joins <const Duration>` in the
contract position, both entering through the specs the tables generate from.
TYPE-045's three rules compose rather than overlap — a `thread async
func:failsafe` earns four refusals between D-177 and D-181, each naming a
different thing wrong.

**B** moved every executor word into `%npk.exec` behind one accessor. Still
one thread, nothing observable changed, and the full harness is what proved
it — which is the point of doing it as its own stage.

**C** made threads real. `clone(2)` rides an **assembly trampoline**, and
that is not a style choice: after the syscall the child runs on a different
stack while every frame offset the compiler laid out belongs to the parent,
so a child that "continues" in IR reads its own uninitialised stack for
anything spilled. The trampoline pops the entry function off the child stack
and calls it with a correct `%rsp`.

Four defects the tests found, each now written where the next reader will
hit it:

1. **The main thread had no `%fs`.** Freestanding means nothing sets it, so
   the first `%fs:8` read was a load from address 8. `npk_tls_boot` gives the
   main thread the same shape `CLONE_SETTLS` gives every other one, so
   `npk_exec` has one path instead of a branch that is right by accident.
2. **`%npk.tls` was used before it was defined** — LLVM sizes a
   `getelementptr null` at parse time, so the type had to be hoisted above
   its earliest user.
3. **The child's executor was `alloc`, not `calloc`.** Queue heads must
   start empty; the first thread this runtime ever started appended its root
   task to a garbage tail pointer.
4. **`PARENT_SETTID` and `CHILD_CLEARTID` are a pair**, and the first cut had
   only the second: the kernel cleared the word at exit but nothing ever
   wrote the tid, so the join read zero, concluded the thread had finished,
   and freed a frame the thread was still running on. The word is both the
   handle and the wake.

Also settled while building: the `joins` clause's expression lives in slot
`b`, where `contract_cond` reads every other clause's — putting it in `a`
made resolve walk `expr_none`, so the name was never bound and the emitter
met an unresolved identifier. **A clause the walkers cannot see is a clause
that silently does nothing.** And `joins` is TYPED by the checker, unlike
`requires`/`ensures` (which are 1.3's and are typed nowhere yet), because it
is not a proof obligation but a value the spawn emits.

`thread_spawn_join.npk` proves both halves of the lexical model: main is not
blocked by a longer-running thread, and the program cannot finish before the
thread does. Remaining for C-9's channel half: `atomic<T>`'s permitted-`T`
set, the channel constructor, `Job`, pools and actors.
